# ADR-0001. Технологический стек

**Статус:** принято · **Дата:** 2026-08

## Контекст

Закрытая платформа для 150–250 участников, из них ~10 за рубежом.
Три нетехнических куратора. Бюджет на инфраструктуру — около 1 500 ₽/мес.
Один разработчик. Проект должен жить годами и передаваться другой команде.

## Решение

Монолит на Next.js (App Router) + PostgreSQL, развёрнутый в Docker на одном VPS.

| Слой            | Выбор                                     |
| --------------- | ----------------------------------------- |
| Язык, платформа | TypeScript (strict), Node.js 22 LTS, pnpm |
| Приложение      | Next.js 16, React 19                      |
| Стили           | Tailwind CSS 4, компоненты на базе Radix  |
| База данных     | PostgreSQL 17, Drizzle ORM                |
| Очереди         | pg-boss (очередь внутри PostgreSQL)       |
| Поиск           | Postgres FTS + pg_trgm                    |
| Вход            | собственная реализация (Telegram HMAC)    |
| Наблюдаемость   | pino, Sentry, PostHog                     |
| Хостинг         | VPS + Docker + Dokploy                    |

## Отвергнутые варианты

- **Разделение на фронтенд и бэкенд.** Удваивает объём работы: два деплоя,
  два набора типов, слой API между ними. При одном разработчике — прямой путь
  к незавершённому проекту.
- **Микросервисы.** Монолит выдержит 10 000 пользователей. У нас 250.
- **Redis.** Кэшировать нечего, очередь помещается в PostgreSQL.
  Каждый лишний сервис — это то, что может упасть ночью.
- **Meilisearch / Typesense.** Оправданы примерно от 3 000 единиц контента,
  у нас будет 280.
- **Vercel.** Бесплатный тариф запрещает коммерческое использование,
  платный — $20/мес и сложности с оплатой из РФ.
- **tRPC / GraphQL.** Server Actions уже дают типизированный вызов сервера.
- **NextAuth / Auth.js.** Наш сценарий входа нестандартный; библиотека будет
  мешать. Собственная реализация — около 300 строк под полным контролем.

## Последствия

- Привязка к Next.js. Смягчается тем, что бизнес-логика вынесена
  в `src/modules` и не зависит от фреймворка (см. ADR-0004).
- Один сервер — одна точка отказа. Закрывается ежедневными бэкапами
  и отработанной процедурой восстановления (шаг F10).
- Обслуживание сервера лежит на команде, а не на облачном провайдере.
